About This Project

🎯 Project Overview

The BDBV Host Prediction System is an advanced machine learning solution designed to predict which animal species are susceptible to Filovirus infection (specifically Bundibugyo virus). Using biological, ecological, and behavioral features, the system provides accurate predictions for both known species in our database and unknown species through intelligent similarity matching.

🚀 Key Features

41 Species Database
Comprehensive animal database with 10,000 training records
51 Features
Viral, host biology, behavior, and risk score features
SVM Model
68.4% ROC-AUC with 46.2% F1-Score
Similarity Matching
20-neighbor interpolation for unknown species
REST API
Flask-based web API for easy integration
Professional UI
Intuitive interface for predictions & analysis
